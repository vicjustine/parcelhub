# Security Policy

## Supported Versions

ParcelHub is pre-1.0 and only the current release line receives security fixes. 

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Report Vulnerabilities privately through Github's
[private vulnerability reporting](https://github.com/vicjustine/parcelhub/security/advisories/new)
rather than opening a public issue. 

Expect an acknowledgment within 3 working days and a status update at least every 7 days
until the report is resolved.

If the report is accepted, a fix is released on the current line and the advisory is published once the fix is available. 
If it is declined, you will get the reasoning in the same thread. 

## Scope
All shipment records in this repository are synthetic, generated by 
'parcelhub.seed'. There is no production deployment and no real customer data.
