# ParcelHub

Internal shipment tracking API for regional parcel operations.

Tracks shipments across three carrier integrations (northline, velocity,
harbourway), exposes lookup and search endpoints, and syncs status feeds
from each carrier's upstream API.

## Layout

    src/parcelhub/api.py      Flask HTTP surface
    src/parcelhub/db.py       SQLite persistence
    src/parcelhub/config.py   YAML configuration loader
    src/parcelhub/seed.py     Synthetic dataset generator
    tests/                    pytest suite

## Running locally

    python -m venv .venv
    .venv/bin/pip install -r requirements.txt
    .venv/bin/python -m parcelhub.seed
    .venv/bin/python -m flask --app parcelhub.api run

## Data

All shipment records are synthetic, generated by `parcelhub.seed`.
